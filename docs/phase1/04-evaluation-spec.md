## 2. 标注规范

### 2.1 标注对象与粒度

**最小可用标注**（POC阶段）：不标字，仅标结构。

| 标注项 | 粒度 | 工作量 | 用途 |
|---|---|---|---|
| 标题层级与父子关系 | 每个标题标 global_level + parent_id | ★★★ | 层级准确率、父子F1 |
| 阅读顺序 | 所有 Block 标 sort_key | ★★ | Kendall τ |
| 表格结构 | 行列数 + 合并单元格 + 跨页归属 | ★★★ | 表格F1 |
| 段落归属 | 段落归属到哪个标题下 | ★ | 文档树F1 |
| 图注配对 | image ↔ caption 配对 | ★ | 图文对象评测 |

### 2.2 不需要标注的部分

- **文字内容**：CER 用 PDF 原生文本层 vs 原始 DOCX 对比即可
- **样式映射**：模板灌注是确定性映射
- **XML 清洗结果**：清洗前后对比

### 2.3 标注原则（文档8.1标注规范）

- 人工基准以**文档语义逻辑**为准，而非原始XML样式
- 标题层级以章节从属语义为 ground truth
- 跨页表格以逻辑上是否为同一表格为判定标准
- 文字基准以原始 DOCX 可编辑文本为准，图片内文字单独统计

### 2.4 标注格式（JSON）

```json
{
  "document_id": "<文档标识>",
  "dirt_level": "light|medium|heavy",
  "annotations": [
    {
      "id": "<节点ID>",
      "type": "heading|paragraph|table|list|image|caption|formula",
      "page": 1,
      "global_level": 1,
      "parent_id": null,
      "sort_key": 0,
      "table_dims": {"rows": 3, "cols": 3},
      "cross_page_pair": null
    }
  ],
  "review_metadata": {
    "reviewer": "<姓名>",
    "review_time": "2026-09-10T12:00:00Z",
    "notes": "..."
  }
}
```

## 3. 评测工具

### 3.1 轻量Web标注工具

为便于用户人工标注，开发一个轻量Web工具：

- 加载DOCX+PDF，左侧显示PDF页面，右侧显示当前标注状态
- 用户点击PDF中的block，系统弹出表单填写标注项
- 标注结果存为JSON（符合2.4格式）

详见：`docs/phase1/05-annotation-tool.md`（待开发）

### 3.2 评测驱动脚本

- `src/docanchor/eval/runner.py`：对单篇DOCX跑Pipeline，对比标注，计算指标
- `src/docanchor/eval/report.py`：批量汇总+分脏度统计
- `src/docanchor/eval/metrics.py`：6个核心指标实现

## 4. 指标计算口径（文档8.2）

| 指标 | 计算口径 |
|------|---------|
| 标题层级准确率 | 全链路径一致（从根节点到当前标题的完整层级路径匹配），非仅末级一致 |
| 章节父子关系F1 | 以节点ID对齐，精确率=正确父子对/输出父子对；召回率=正确父子对/基准父子对 |
| 阅读顺序Kendall τ | 按全文阅读流排序，计算输出顺序与基准顺序的秩相关系数 |
| 表格单元格F1 | 包含合并单元格、空单元格；表头重复不计入错误；按单元格位置+内容匹配 |
| 普通文本CER | 中文字符粒度，标点、全半角统一归一化后计算；纯视觉识别区块单独统计 |
| 人工复核占比 | 分脏度等级分别统计 |

## 5. POC阶段验收目标（文档8.3，调整后）

按用户决策，中度样本必须达标，轻度尽力达标，重度尽量跑通。

| 指标 | 轻度 | 中度 | 重度 |
|------|------|------|------|
| 标题层级准确率 | ≥95% | ≥92% | ≥85% |
| 章节父子关系F1 | ≥93% | ≥90% | ≥82% |
| 表格行列准确率 | ≥97% | ≥95% | ≥88% |
| 关键字段准确率 | ≥99% | ≥99% | ≥97% |
| 普通文本CER | ≤0.3% | ≤0.5% | ≤1% |
| 人工复核占比 | ≤8% | ≤15% | ≤30% |

> **重要**：由于样本量从50篇缩减到5-10篇，三档指标统计的置信区间极宽，验收按"中度核心指标达标"为准，不要求完整三档分布。

## 6. 通过规则（文档8.4）

- POC验收：中度脏文档核心指标达标，重度脏文档核心指标不低于下限
- 不采用badcase一票否决，按批量均值判定
- 允许存在已知边界case，纳入迭代优化
- POC阶段验收结论仅用于判定是否进入下一研发阶段
